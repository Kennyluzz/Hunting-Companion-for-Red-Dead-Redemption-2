# Hunting Companion

An in-game companion for Red Dead Redemption 2 (Story Mode).

## Install

1. Install ScriptHookRDR2 and an ASI loader if you do not already have them.
2. Copy `HuntingCompanion.asi` into the game folder, beside `RDR2.exe`.
3. Start Story Mode and press **F8**. Language, hotkeys and the weapon/ammo icons
   can be changed on the in-game Settings page.

Do not use it with Red Dead Online.

## Notes

- Japanese, Korean and Chinese text on a game set to another language needs the
  Vulkan renderer. Otherwise the mod shows English.
- Settings are saved to `HuntingCompanion.ini` next to the `.asi`.
